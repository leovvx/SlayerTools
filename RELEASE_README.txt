SLAYER TOOLS - in-game mod menu for Idle Slayer
================================================

INSTALL
  1. Install BepInEx 6.0.0-be.788 IL2CPP (win-x64) in the game folder and start the game once.
  2. Copy SlayerTools.dll into:
     C:\Program Files (x86)\Steam\steamapps\common\Idle Slayer\BepInEx\plugins\
     (replace the old one if there is one).
  3. Start the game, open the game menu and click the star tab (or the star button at the top left).

UNINSTALL
  Delete BepInEx\plugins\SlayerTools.dll. The game files are never modified.

LOG
  BepInEx\LogOutput.log - every line from the mod starts with [Slayer Tools].

Single-player only: Jewels of Soul, purchases and the online casino are not touched.

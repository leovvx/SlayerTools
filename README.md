# Slayer Tools

A BepInEx mod for **Idle Slayer** (Steam, PC) that adds a native in-game menu to tinker with your own single-player progress: stats, resources, divinities, events, chest hunts, bosses…

> Current version: **6.1.0** · Target game: **Idle Slayer 7.3.6** (Unity 6, IL2CPP) · Loader: **BepInEx 6.0.0-be.788 IL2CPP x64**

## Quick start

```powershell
# 1. Install the .NET 8 SDK (once)
winget install Microsoft.DotNet.SDK.8

# 2. Build and copy the DLL into BepInEx\plugins (game closed)
cd $env:USERPROFILE\Downloads\SlayerTools-en
.\build.ps1
```

Then start Idle Slayer and press **F2** (or click the **star tab** in the game menu, or the star button at the top left). The menu reopens where you left it.

## How it works

The mod changes **no game file**. BepInEx loads `SlayerTools.dll` at startup; the plugin:

1. **patches a few game methods in memory** with Harmony (block the anti-mod quit, god mode, keep edited stats…);
2. **clones the game's own UI elements** (buttons, text field, tabs) to build its pages inside the "Info" panel, so the menu looks exactly like the game;
3. **reads and writes game objects** (`PlayerInventory`, `Drop`, `Divinity`, `ChestHuntManager`…) through the interop assemblies generated by BepInEx.

Removing `SlayerTools.dll` from the `plugins` folder makes the game 100% vanilla again.

## Limits

Single-player only. Jewels of Soul and purchase-related stats are **read-only**, and the mod never touches online transactions or the server-side casino (roulette, slots, cashier). See [docs/LIMITATIONS.md](docs/LIMITATIONS.md).

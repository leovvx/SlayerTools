# Idle Slayer internals

Reverse-engineering notes on **Idle Slayer 7.2.0**, checked again against the **7.3.6** interop (Unity 6000.3.14f1, IL2CPP). Names come from the interop assemblies generated by BepInEx; behaviours were checked in the disassembly (see [TOOLS.md](TOOLS.md)).

## Anti-mod protection
`SplashScreen.LoadGameScene` and `PlayerInventory.Awake` call `Application.Quit()` if one of these paths exists next to the game:
- `../MelonLoader`, `../dotnet`
- `../doorstop_config.ini` (installed by BepInEx)

→ Bypassed with a Harmony prefix on `Application.Quit` that only lets real exits through (`UIManager.ExitGame`, `WaitForUploadAndQuit`).

## Save file
- `%USERPROFILE%\AppData\LocalLow\Pablo Leban\Idle Slayer\savedata.sav` (+ `backup.sav`)
- JSON (`StringData`, `IntData`, `FloatData`, `BoolData`) **XOR**-encrypted with a 78-character text key.
- Firebase cloud sync keeps the save with the most Slayer Points.

## Chest hunt
- `ChestHuntManager.GenerateChests()` is called once from `StartEventDelayed`: **every type is known before the first chest is opened**.
- `Chest`: `type`, `opened`, `multiplier`, `chestObject` (`ChestObject`: `revealText`, `Open()`, `Reveal()`).
- `ChestType`: `None 0, Mimic 1, Special 2, Multiplier 3, CPS 4, SlayerPoints 5, Both 6, Saver 7, ArmoryChest 8, DuplicateNextPick 9, PermanentUpgrade 10, MultiplierIncreaser 11`.
- `Chest.SetType` is only called from `GenerateChest`.

## Boost / abilities
`Ability.currentCd` (float): ready when ≤ 0. Setting `0.0001` lets the game itself move it to 0 and fire `AbilityReady` (so the UI updates).

## Quests
`Quest.ForceComplete(bool alsoClaim)`, `IsCompleted()`, `CanBeCompleted()`, `isClaimed`, `questCurrentGoal`, `questGoal`, `localizedName`.

## Resources (bag)
`Drop`: `name`, `localizedName`, `icon` (Sprite), `amount`, `maxAmount`, `GetMaxAmount()`, `locked`, `category` (`DropCategory.sortingOrder`). Full list: `PlayerInventory.instance.drops`.

## Divinities
`Divinity`: `id`, `localizedName`, `icon`, `cost`, `unlocked`, `isDark`, `SaveData()`, `divinityObjectComponent.RefreshColors()`.
Available points = `PlayerInventory.divinityPoints` − sum of `cost` of `unlocked` divinities. `DeactivateDivinity` refunds points for free.

## Casino (online)
`CasinoManager.PlayRoll`, `SpendChips`, `BuyItem`… are **asynchronous methods with callbacks** (success / not enough chips / error) that talk to the server. Chips and rolls are handled **server-side**. See [LIMITATIONS.md](LIMITATIONS.md).

## Il2CppInterop pitfalls
- Some Unity methods are re-implemented in the interop assemblies with code that uses `Il2CppSystem.Span` / `ReadOnlySpan`. Calling them throws `MissingMethodException: ... ReadOnlySpan`1.GetPinnableReference()` at runtime, although the plugin compiles. Known case: `UnityEngine.ColorUtility.TryParseHtmlString` (v6.0.0 crashed on it while building the menu). Run `tools/interopscan` on a new build to catch these before testing in game.
- Methods of the injected `ToolsBehaviour` that take managed types (`Func<>`, `List<>`, nested classes) are reported as "unsupported parameter" by Il2CppInterop at startup. This is harmless: they are only called from managed code.
